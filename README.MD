## CareerProof

**Multi-Agent Career Verification AI**

CareerProof is a multi-agent AI system that evaluates the evidence,
assumptions, risks, and realistic alternatives behind a student's career plan.

Instead of simply recommending careers, the system attempts to
**verify whether a proposed career path is realistically supported by evidence**.

### Architecture

`Profile → Evidence → Critic → Reality → Alternatives → Report`

### Features

- Six-agent architecture
- Student profiling
- Evidence analysis
- Hidden-assumption detection
- Critical review
- Reality checking
- Alternative-path analysis
- Structured verification reports

Built with **Microsoft Copilot Studio** for a software and AI hackathon.
